# Workout Tracker V4 — Winter Muscle Builder + Expanded Home Variety

V4 activates the approved 5-week Winter Muscle Builder when upgrading from an earlier program version while preserving existing workout history, notes, PR data, substitution preferences, and cloud-backed state.

## New gym block
- Weighted Pullups naming finalized
- Machine Leg Curl is intentionally a new exercise variation and is tracked separately from the prior Seated Leg Curl
- Moderate hypertrophy rep ranges and double progression
- Week 5 deload remains at about 90% of the last normal working weight with reduced sets

## Home generator upgrades
- Much larger Garage exercise pool
- More bodyweight movements
- Many more TRX movements
- More kettlebell and sandbag carry variations
- Garage jump-rope options retained
- Basement conditioning continues to emphasize treadmill work
- Weighted-vest treadmill work is walking only; faster intervals are no-vest
- No jump rope in the Basement
- Ab roller and leg-curl roller remain available in both locations
- Recently generated movements are deprioritized to reduce repetition
- Home workouts remain disposable and do not affect A/B/C history or progression
- The next gym workout is still only a soft fatigue constraint

## Existing V3 features retained
Approved substitutions, exercise-level RPE, per-exercise timers, supersets/override support, workout summaries, PRs, progress charts, missed-set logic, deload logic, remote program support, and automatic Firebase cloud backup.

## Important Firebase note
This update package intentionally does **not** include `firebase-config.js`. Leave your existing GitHub `firebase-config.js` untouched so your current Firebase connection remains active.
